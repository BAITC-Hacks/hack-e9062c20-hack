# hack-e9062c20-hack

Скрипт `src/hack_e9062c20_hack/segmentation.py` читает обращения из `messages.txt`,
отправляет их в OpenAI Responses API и печатает для каждого категорию (`справка`,
`жалоба` или `другое`) и короткий черновик ответа на русском языке. Один запрос
возвращает структурированный JSON, поэтому порядок обращений сохраняется, а
категория ограничена тремя допустимыми значениями.

## Запуск

Нужны Python 3.12+, зависимости проекта и ключ OpenAI API. Ключ хранится в `.env`
в корне проекта:

```env
OPENAI_API_KEY=ваш_ключ
```

Запуск через `uv`:

```bash
uv run python src/hack_e9062c20_hack/segmentation.py
```

Можно передать другой файл обращений:

```bash
uv run python src/hack_e9062c20_hack/segmentation.py path/to/messages.txt
```

По умолчанию используется `gpt-4o-mini`; модель меняется параметром `--model`.
Скрипт сам читает простой `.env`, не выводит ключ и не требует отдельной dotenv-библиотеки.

## Что получилось

Для пяти строк из текущего `messages.txt` программа печатает пять блоков: исходное
обращение, категорию и вежливый черновик ответа. Запросы о месте учёбы и парковке
относятся к справочным, сообщения о очереди, холодной еде и Wi‑Fi — к жалобам,
а запись на консультацию обрабатывается как отдельное обращение. Ответы не
выдумывают факты и предназначены для проверки оператором перед отправкой.
